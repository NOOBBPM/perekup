# Авторынок — Telegram-бот

Бот на Python и aiogram 3 с SQLite-хранилищем. Он содержит три автомобильных рынка, контейнеры со случайными взвешенными наградами, осмотр с торгом, покупку конкретного объявления сразу или после торга, гараж, продажу с подтверждением, работу с перерывом в пять минут, уровни, рейтинг по трём категориям, промокоды, глобально уникальные номера и разовую скрутку пробега с отметкой. Цена каждого нового объявления случайно меняется на ±150 000 ₽ и не заканчивается на «00».

«💼 Работа» открывает карточку с inline-кнопкой «💼 Работать». При успешной смене карточка обновляется с заработком; во время пятиминутного перерыва оставшееся время показывается только во всплывающем уведомлении Telegram, без нового сообщения в чат. Повторное нажатие показывает актуальный остаток времени.

Кнопка «🔗 Рефералка» рядом с промокодом показывает личную ссылку с кнопками копирования и отправки. Только новый зарегистрированный игрок, впервые открывший её в личном чате, получает +100 000 ₽ и +5 репутации; пригласивший получает +150 000 ₽ и +5 репутации. Самоприглашение и повторные заходы наград не дают.

Личные игровые меню в группах доступны только игроку, который их открыл. Другим бот показывает всплывающее «Это не твоё меню», не изменяя сообщение, баланс или состояние ввода. Владельцы меню сохраняются после перезапуска. Старые групповые меню, отправленные до этой защиты, нужно открыть заново. Публичные респекты и присоединение к PVP остаются общими; кнопки самой игры доступны её двум участникам.

## Настройка

- `TELEGRAM_BOT_TOKEN` — токен BotFather, хранится в Replit Secrets.
- `ADMIN_TELEGRAM_IDS` — необязательный список Telegram ID через запятую. Без него игровые функции работают, но команды администратора закрыты. Свой ID можно посмотреть командой `/id`.

Команды администратора:

- `/admin` — справка
- `/promo CODE СУММА [ЛИМИТ]` — создать промокод
- `/promos` — список промокодов
- `/promodel CODE` — удалить промокод
- `/plate А123ВС77 ID` — назначить машине российский номерной знак
- `/reset ID` — сбросить только лимит контейнеров игрока и начать новое часовое окно
- `/cont` — дневная статистика контейнеров по времени Europe/Saratov
- `/stats` — статистика слотов за последние 7 дней (оборот, выплаты, RTP и топ игроков)

Кнопка «🛠️ Админ панель» доступна только ID из `ADMIN_TELEGRAM_IDS`. Во всех действиях с игроком можно указать его Telegram `@ник` (без учёта регистра, также допускается ник без `@`): выдать/списать деньги, выдать номер или машину, изменить репутацию, обнулить прогресс с подтверждением, забанить или разбанить. Игрок должен быть зарегистрирован в боте; после смены ника ему нужно отправить `/start`. При неоднозначном совпадении операция не выполняется. Для игроков без ника остаётся возможность указать ID.
Деньги выдают строкой `@player 100000`, номер — `@player А123ВС77`, машину — `@player название цена л.с. пробег номер`; для машины без номера укажи `-`.
Подтверждённый сброс устанавливает баланс в 0, удаляет машины и номера со склада, сбрасывает лимиты контейнеров; статус бана при этом сохраняется.
Игроки могут ввести промокод кнопкой «🎁 Промокод» или командой `/code CODE`.
Рейтинг открывается кнопкой «🏆 Топ»; можно выбрать баланс, уровень или репутацию.
Кнопка «📦 Контейнеры» или команда `/containers` открывает контейнеры «Европа», «США» и «Япония». Лимит всегда равен трём открытиям за час, улучшения его не увеличивают. Счётчик и списание денег хранятся в базе и не теряются при перезапуске. Для получения машины нужно свободное место в гараже. Машина получает случайные характеристики и уникальный российский номер.
С вероятностью 20% вместо машины выпадают деньги: Европа и Япония — 1–10 млн ₽,
США — 1–7 млн ₽, случайная сумма с шагом 1 ₽. Остальные 80% открытий выдают
машины с прежними относительными весами редкости. В Европе добавлены BMW M4 F82
и Mercedes-AMG GT; в США — Ford F-150 и Dodge Viper.
В авторынке также доступны все модели контейнеров, которых нет в автосалонах:
цена контейнера используется как базовая, затем действует обычное колебание
рыночного предложения ±150 000 ₽.
Для открытия любого контейнера по-прежнему нужно свободное место: нельзя
получить только денежные исходы бесплатными повторами при заполненном гараже.
Открытие показывает двухсекундную паузу перед результатом. Плата, награда и запись в журнале сохраняются до показа анимации, чтобы прерывание бота не потеряло награду. Деньги сразу поступают на баланс, машину и номер при денежном выигрыше не создаём. Журнал ведётся с момента добавления этой системы; прошлые открытия не восстанавливаются. Старые записи сохраняются как автомобильные; статистика включает обе разновидности наград.
В гараже можно снять номер за 10 000 ₽, хранить его на складе и назначить другой машине.
Фотографии подключены для 194 из 235 моделей рынка, контейнеров и машины ежедневной
награды. Снимок отправляется
над отдельной текстовой карточкой рынка, гаража, публикации и результата
контейнера, если модель окажется в его составе. Сейчас в контейнерах Ghost
нет, их состав не изменён. Вся информация и кнопки остаются на текстовом
сообщении; осмотр, торг и другие действия никогда не заменяют текст фото.
Связь карточки с фото хранится между перезапусками, чтобы не слать снимок
повторно при каждом нажатии. Изображение сохранено локально, без зависимости
от доступности YouTube при открытии меню.
Фото комфорт-класса проверены и сохранены локально в JPEG до 800×600, поэтому
бот не зависит от доступности внешних ссылок при показе карточки.
Дополнительные фотографии сохранены в JPEG до 700×525; исходные ссылки находятся
в assets/cars/photo-sources.csv. Priora, Granta и Vesta используют ссылки пользователя;
для Kalina подобран другой снимок, поскольку присланная ссылка возвращала HTTP 403.
Фото есть у всех 259 моделей автосалонов и контейнеров. Без подстановки снимков
другой модели, коллажей, деталей автомобиля или игрушек.
Для Skoda Kodiaq 2019 использована отдельная исправленная ссылка пользователя,
не снимок Volkswagen Passat. При ошибке загрузки любого подключённого изображения
бот указывает модель в предупреждении и сохраняет текст и кнопки.
Годы моделей в игре не изменены: фото подписанные RAV4 2018, Qashqai 2018
и Tucson 2018 сопоставлены с существующими RAV4 2019, Qashqai 2017 и Tucson 2019.
Скрутка пробега уменьшает одометр на 40% один раз; в гараже и перед продажей появляется предупреждающая отметка.

## Финансы и банк

Главная кнопка «💰 Финансы» открывает работу и «🏦 Банк (кредиты)».
Один активный кредит на игрока; доступные суммы по уровням:
300 000, 500 000, 1 000 000, 5 000 000, 10 000 000, 15 000 000 ₽.
Полное погашение до истечения срока повышает уровень на один (максимум 6).
К возврату начисляется 20%; срок — 48 часов с получения.
При продаже машины 40% положительной чистой прибыли автоматически погашают
кредит, но не больше остатка долга. Вложения и потолок прибыли 1,5 млн
считаются до этого платежа. Сумма погашения показана в оффере и результате продажи.
Можно погасить кредит вручную; подтверждения защищены от повторной обработки.
По истечении срока остаток принудительно списывается, даже в отрицательный баланс.
Проверка идёт раз в секунду, пока бот работает; после остановки просрочки
обрабатываются при следующем запуске. Минус запрещает брать новый кредит.

Свой банк открывается за отдельные невозвратные 30 млн ₽. Капитал пополняется
с баланса владельца и должен составлять не менее 50 млн ₽ для новых кредитов.
Капитал = свободные деньги + невозвращённый основной долг заёмщиков.
Выдавать можно только реально свободные деньги. Игрок выбирает только личные
банки из глобального топ-10 по капиталу; государственный банк удалён.
Список заёмщика сортируется по убыванию капитала. При равном капитале первым
стоит банк с меньшим ID. Исключение своего банка или банков без ликвидности
не продвигает 11-й банк в топ-10. Кредит самому себе запрещён.
Погашения возвращают капитал; реально полученные проценты поступают в банк.
Владелец может выводить свободные деньги, но снижение капитала ниже 50 млн
приостанавливает новые выдачи. Ранее выданные кредиты продолжают обслуживаться.
Выход из топ-10 также блокирует только новые кредиты; существующие долги
сохраняют срок и погашение, включая кредиты старого государственного банка.
Позиция проверяется заново в момент фактической выдачи.

При открытии игрок вводит название длиной 3–40 символов в одну строку,
затем подтверждает плату 30 млн ₽. Старые банки сохраняют деньги и временно
получают имя «Банк #ID». В «Мой банк» доступны топ по капиталу и настройки.
В настройках можно ввести новое название и подтвердить переименование
за 10 млн ₽ с личного баланса владельца, не из капитала банка.
Повторное подтверждение не должно повторно списывать плату.

Перед первым снятием старого ограничения неотрицательного баланса создаётся
локальная SQLite-копия `*-before-bank.sqlite3`; игроки, связанные записи,
индексы и триггеры сохраняются.

## Проверки машин, торг и свалка

Новые объявления и новые машины из контейнеров или выдачи администратора получают
скрытые параметры: 0–5 окрашенных деталей, скрученный пробег с величиной скрутки
и историю работы в такси. При покупке параметры объявления переходят к машине.
У уже существовавших машин миграция не создаёт новые дефекты.

В карточке рынка толщиномер за 3 000 ₽ показывает окрашенные детали, а Автотека
за 5 000 ₽ — скрутку и такси. Каждая проверка оплачивается один раз для объявления;
повторный просмотр бесплатный. После нового отчёта нужно снова нажать «Торговаться».
Неоплаченные сведения скрыты и скидку не дают.
Покупка доступна сразу по цене продавца; проверки и торг необязательны.

Торг рассчитывается от исходной цены: 2/3 окрашенные детали дают 20/30%, 4 — 60%,
5 — 80%; выявленная скрутка даёт ещё 15%, такси — ещё 10%. Общий предел — 80%.
Повторные торги не накапливают скидку. Без оплаченных находок цена остаётся исходной.

Машины с 4–5 окрашенными деталями отмечены в гараже как утиль: обычная продажа
недоступна, вместо неё есть кнопка сдачи на свалку с подтверждением и отменой.
Свалка платит 20% исходной рыночной стоимости с ограничением прибыли 1 500 000 ₽ сверх вложений и без
начисления репутации/опыта. Установленный номер уходит вместе с машиной; чтобы
сохранить его, сначала нужно снять номер.

## Покупатели и вложения при продаже

Карточка продажи показывает имя покупателя, все вложения в машину, конкретный
оффер и итог «ПЛЮС/МИНУС». Базовый оффер случайный: 70–115% рыночной цены,
но выплата не превышает вложения плюс 1 500 000 ₽. Улучшение цены продажи отключено.
Кнопка «Продлить объявление» меняет покупателя раз в 15 секунд; цена также меняется,
но при достижении потолка может остаться прежней. Текущий покупатель и
задержка сохраняются в базе: отмена, повторное открытие и перезапуск не дают
новый оффер бесплатно. Старая кнопка после изменения оффера только обновляет
карточку; продажа требует подтверждения текущей версии.

Вложения включают стоимость покупки и оплаченных отчётов, затем фактические
расходы на ремонт, снятие номера и скрутку пробега. Для контейнерной машины начальное вложение —
плата за открытие контейнера; для выдачи администратора — заданная цена машины.
Общие места и улучшения гаража не распределяются на одну конкретную машину.
Изменение расходов на машину обновляет версию подтверждения, чтобы старый
экран не скрывал изменившийся итог. Тюнинга в текущей игре пока нет.

При миграции старых машин восстанавливаются покупная стоимость и ремонты,
сохранённые в журнале. Исторические снятия номеров не записывались, поэтому
неизвестные суммы не выдумываются. Подтверждение переводит ровно показанную
сумму один раз, удаляет машину и начисляет стандартные +1 репутации/+25 опыта.

## Гараж и улучшения

Кнопка «🏎️ Гараж» или `/garage` показывает места и машины. Новые игроки получают 3 места. При первом включении системы старым игрокам выделяется не меньше мест, чем у них уже есть машин; никакие машины не удаляются. Покупки на рынке, контейнеры и выдача машин администратором проверяют вместимость.

Гараж показывает до шести машин на странице; список содержит модель, номер, мощность и stage. У каждой машины есть отдельная кнопка «Меню», открывающая карточку с действиями. Между страницами можно переключаться кнопками внизу; улучшения гаража открываются отдельно. В улучшениях осталось только добавление одного места с растущей ценой; отдельная покупка места за фиксированную цену удалена. Кнопки и команда истории расходов также убраны. Все действия находятся в отдельной карточке машины: номера, платная скрутка пробега (5 000 ₽), ремонт, продажа/свалка и публикация для респектов. Карточка показывает вложения, состояние и дефекты; счётчик продаж относится к игроку, а не к машине. Отмена подтверждения возвращает в карточку, успешная продажа — на исходную страницу списка.

В меню улучшений цена растёт по формуле `база + шаг × текущий уровень`:

- Место +1: база 250 000 ₽, шаг 50 000 ₽.
Улучшения продажи, ремонта и лимита контейнеров больше недоступны; ранее купленные уровни не дают бонусов. Записи о расходах на них сохраняются в истории.

Ремонт по кнопке в карточке машины восстанавливает состояние до 100%. Цена — 0,1% оценочной стоимости за каждый недостающий пункт состояния, без улучшений и скидок. Повторный ремонт исправной машины не списывает деньги. При изменившейся цене улучшения места старая кнопка обновляет меню без списания.

Полный сброс игрока в админ-панели также удаляет улучшения и возвращает вместимость к 3 местам. `/reset ID` по-прежнему сбрасывает только часовое окно контейнеров. Сохранённые ранее записи расходов остаются в базе и не удаляются, но в игровом меню больше не показываются.


## Хранение данных

База создаётся автоматически в `telegram_bot/data/perekup.sqlite3`. Токен не записывается в базу или логи. Для резервной копии останови бота и скопируй файл базы.

Основной каталог содержит 69 автомобилей из присланного списка: 25 эконом, 24 комфорт и 20 бизнес. Для контейнеров отдельно настроены 18 моделей с разными шансами выпадения.
## Публикации машин и респекты

В гараже у каждой машины есть кнопка «Выложить тачку». Она отправляет карточку в текущий чат, не меняя страницу исходного гаража. В группе можно опубликовать собственную машину командой `/show_car ID`; ID указан в гараже. Если для модели есть фото, оно и характеристики, номер, имя владельца и кнопки публикуются одним сообщением с подписью; без фото отправляется текстовая карточка.

Счётчик `cars.respect` общий для машины и сохраняется при новых публикациях и перезапуске. У каждой публикации свой ID и свой набор голосов: один игрок (включая владельца) может поставить один респект за публикацию. Повторный клик только обновляет число на кнопке. Голос и увеличение счётчика записываются вместе; параллельные клики не дают дубликатов. После продажи/удаления машины её старые кнопки сообщают, что машина недоступна.

## Аукцион номеров

Кнопка «🏷️ Аукцион номеров» или `/auction` открывает меню с двумя кнопками: «Ставки» и «Выставить номер». Активные лоты показаны компактным списком с одной кнопкой ставки на лот; список листается по страницам.

Выставить свободный номер можно только кнопкой «🎲 Выбрать номер из склада» или командой `/sell_plate`, затем выбрать номер inline-кнопкой. Лот автоматически создаётся на 1 час по стартовой цене номера. В реестре номеров стартовая цена по умолчанию — 100 000 ₽; для уже существовавших номеров это значение добавляется при миграции. Ручные цена и срок не вводятся. Ставка выбирается кнопкой: к цене на экране прибавляется 100 000 ₽ или 250 000 ₽. Если ставка устарела, кнопки обновляются без списания большей суммы. Минимальный шаг — 10 000 ₽. Нельзя ставить на собственный лот. Команда `/bid ID_ЛОТА` открывает кнопки выбора ставки.

За каждое успешное выставление номера списывается 30 000 ₽, без возврата даже при отсутствии покупателя. Сбор показывается до нажатия кнопки; неудачное или повторное создание того же активного лота не списывает деньги. На уже выставленные лоты новый сбор не начисляется.

Деньги лидирующей ставки резервируются; перебитому участнику они возвращаются сразу. Свою лидирующую ставку повышать нельзя: бот показывает «Твоя ставка уже лидирует». После перебития другим игроком можно поставить снова. Лоты закрываются раз в минуту и при просмотре/обращении к истёкшему лоту. Победителю переходит номер, продавцу — сумма за вычетом комиссии 5%. Повторное закрытие не начисляет деньги снова. Без ставок номер остаётся у продавца, сбор за выставление не возвращается.

Во время торгов номер скрыт из доступного склада и не может быть установлен на машину. Полный административный сброс отменяет активные лоты сбрасываемого продавца или лоты, где он лидирует, возвращая текущие резервы; история сохраняется.

## Хранение данных

База создаётся автоматически в `telegram_bot/data/perekup.sqlite3`. Токен не записывается в базу или логи. Для резервной копии останови бота и скопируй файл базы.

Основной каталог содержит 69 автомобилей из присланного списка: 25 эконом, 24 комфорт и 20 бизнес. Для контейнеров отдельно настроены 18 моделей с разными шансами выпадения.
